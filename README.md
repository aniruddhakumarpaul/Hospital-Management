# LifeCare AI - Hospital Management System

Welcome to the **LifeCare AI** terminal repository. This system provides automated patient registration, AI-driven triage, and a secure provider portal.

## 🔑 Access Credentials

### Doctor Portal
- **Login URL**: `http://localhost:8080/doctor-dashboard.html`
- **Access Password**: `doc-pass-2026`

## 🏥 Core Features
- **AI Triage**: Automatic department suggestions based on patient symptoms.
- **Payment Enforcement**: Automated audit for unpaid balances during registration.
- **Emergency Bypass**: Life-threatening cases can override financial holds with aggregated billing.
- **Doctor Dashboard**: Real-time patient volume tracking and treatment management.

## 🚀 Getting Started
1. Run `Start_LifeCare_AI.bat` to launch the server and kiosk.
2. Select **"Kiosk Terminal"** for patient self-registration.
3. Select **"Doctor Portal"** and enter the password above to manage patients.
